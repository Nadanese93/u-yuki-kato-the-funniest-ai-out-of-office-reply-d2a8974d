This entry is one funny out-of-office auto-reply for the make.fun bounty "The Funniest AI Out-of-Office Reply" ($5 prize). The reply is under 160 characters: while its owner is on vacation, the only replacement on duty is a CAPTCHA, and every sender must first prove they are human to proceed. `main.py` (Python 3 standard library only, deterministic, no network) writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
